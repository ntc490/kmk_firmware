# Kubocho

The [Kubocho]() is a hand-wired, split, 42 key keyboard, designed after
the Kinesis Advantage, but modified with more modern thinking.

# Feature Ideas
- Haptic feedback for home-row mods and layer switches
- Under-glow using LED strips
- Pedometer to measure work for the day - send via morse code
- Hand detection for auto layer switching
- Tickler
  - Multiple timeouts
  - Presence detection logic
- Presence detection tied to tickler
- Timer support for sitting and standing
- Backlit keys
- Built-in thumb-trackball for quick changes?
- USB hub for Yubikey and other devices
- Display:
  - pedometer
  - tickler mode
  - backlight modes
  - animations
  - layer status
  - keyboard specs (switches, number of keys, name, author, etc)
  - module auto-detection
  - interactive command prompt
- Remote control mode - key sequences from SSH session through HID interface
- Config via keyboard commands
- Chording mode for by-the-word-typing
